# 东软 NIS 护理 PDA 接口 `WebToPIO` 调用流程（Postman）

本文档描述如何使用 **Postman** 调用东软 NIS 系统的 `WebToPIO` 方法，该接口接收一个 JSON 字符串，返回整数结果（-1/0/1）。

---

## 1. 接口基本信息

- **接口地址**：`http://182.168.10.125:11004/Neusoft.NIS.NursingProcess.BllFacade.IPDAFacade.svc`
- **方法名**：`WebToPIO`
- **入参**：`string json` （一个 JSON 格式的字符串）
- **返回值**：
  - `-1`：调用失败
  - `0`：调用成功，未生成待诊断
  - `1`：调用成功，生成待诊断

---

## 2. Postman 配置步骤

### 2.1 新建请求

| 属性   | 值                                                           |
| ------ | ------------------------------------------------------------ |
| Method | **POST**                                                     |
| URL    | `http://182.168.10.125:11004/Neusoft.NIS.NursingProcess.BllFacade.IPDAFacade.svc` |

### 2.2 设置请求头（Headers）

| Key            | Value                                      | 说明                                                         |
| -------------- | ------------------------------------------ | ------------------------------------------------------------ |
| `Content-Type` | `text/xml; charset=utf-8`                  | 声明发送的是 XML 格式数据                                    |
| `SOAPAction`   | `"http://tempuri.org/IPDAFacade/WebToPIO"` | **必须**，用于路由到具体方法。若报错可尝试去掉双引号或改为 `*` |

### 2.3 设置请求体（Body）

- 选择 **raw**
- 格式选择 **XML**

#### 完整 SOAP 信封模板（已转义 JSON 中的双引号）

```xml
<s:Envelope xmlns:s="http://schemas.xmlsoap.org/soap/envelope/">
  <s:Header/>
  <s:Body>
    <WebToPIO xmlns="http://tempuri.org/">
      <json>{"PatientID":"ZY0101102031","PatientName":null,"EmrAssessList":[{"Guid":"","AssItemId":"12312412dfsf","AssItemName":"风险名","AssDate":"2022-10-13T17:10:05.7722412+08:00","AssResult":"10","AssevalorCode":"200355","AssevalorName":"hushiming","FileDataId":"","DiagFrom":"VTE"},{"Guid":"","AssItemId":"1231232412dfsf","AssItemName":"风险名1","AssDate":"2022-10-13T17:10:05.7722412+08:00","AssResult":"5","AssevalorCode":"200355","AssevalorName":"hushiming","FileDataId":"","DiagFrom":"VTE"}]}</json>
    </WebToPIO>
  </s:Body>
</s:Envelope>
```

> **重要**：JSON 中的双引号必须使用 `&quot;` 转义，否则 XML 解析会出错。

---

## 3. 参数说明（JSON 字段）

| 字段名          | 类型     | 注释                              |
| --------------- | -------- | --------------------------------- |
| PatientID       | string   | 患者流水号（必填）                |
| PatientName     | string   | 患者姓名（可为 null）             |
| EmrAssessList   | array    | 评估列表                          |
| ├ Guid          | string   | 唯一标识（可为空）                |
| ├ AssItemId     | string   | 评估术语 ID                       |
| ├ AssItemName   | string   | 评估术语名称                      |
| ├ AssDate       | datetime | 评估时间（ISO 8601 格式，含时区） |
| ├ AssResult     | string   | 分数                              |
| ├ AssevalorCode | string   | 评估人 ID                         |
| ├ AssevalorName | string   | 评估人姓名                        |
| ├ FileDataId    | string   | 文件数据 ID（可为空）             |
| └ DiagFrom      | string   | 数据来源（如 VTE）                |
